Note that bC supports = for all types of arrays. 
It does not support relative testing: ≥, ≤, >, < for any arrays.

Notes:
?n generates a uniform random integer in the range 0 to |n|-1 
with the sign of n attached to the result. 
?5 is a random number in the range 0 to 4. 
?-5 is a random number in the range 0 to -4. 
?0 is undefined.

x :<: y returns the smaller of the two integers.
4 :<: 5 returns 4.

The unary * takes an array as an argument and returns the size of the array.
like: *myArray

The logical operators & and | are NOT short-circuiting.
